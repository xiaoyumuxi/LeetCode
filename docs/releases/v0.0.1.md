# LeetCode 0.0.1

首个公开预发布版本，在 Lithe 中浏览题库、创建解题文件，并接入在线判题。

- 支持中文站、国际站题库搜索、筛选、每日一题与文本题面。
- 从题目的真实模板创建解题文件，已有文件直接打开，不覆盖代码。
- 中文站题解和热门顶层讨论可在编辑区只读标签页打开。
- 在线样例和提交使用当前编辑器内容，上传前确认；完成后的判题报告进入「运行」面板，可重复查看而不重新提交。
- 提供中英文界面、深浅主题、LeetCode 图标及页面与后端版本不一致提示。

提供 macOS、Windows、Linux 各自的 arm64 和 x64 安装包：`LeetCode-0.0.1-<darwin|windows|linux>-<arm64|x64>.zip`，按 Lithe 宿主的系统和架构选择，在 Lithe 中从磁盘安装。各包附带 SHA-256 文件。Windows 与 Linux 四个包从同一个 `v0.0.1` 原始提交补充构建，已发布的 Mac 包不替换；各平台的最终桌面与真实账号工作流均待用户验收。

本版本依赖开发版宿主能力，参考提交见 `sdk.lock.json`，通用修复见 [Lithe #2383](https://github.com/1lck/Lithe-IDEA/pull/2383)（已合入）。旧宿主可能缺少所需 API 或仍显示通用图标、遮住浮层、丢失错误分类；因此本次标为预发布，不宣称兼容当前稳定版宿主。

登录按钮打开官方浏览器登录页；浏览器会话尚不能自动回传插件，仍需手动关联 Cookie 并验证账号。国际站社区、图片公式及会员内容请在原网站查看。取消仅停止本地等待，远端任务可能继续，超时后应查询原任务而非重复提交。

按要求只构建发布包，没有运行最后代码的测试、静态检查或桌面验收；真实账号登录和判题流程待用户验收。此前安装的本地开发包版本号高于本次首发号，属于未公开开发版本；已有安装请先卸载插件再安装 `0.0.1`，不要删除个人解题文件。
